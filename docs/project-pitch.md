# Target Audience and Need

## Overall Need
* effective method to plan travel with multiple people
* streamlined way to budget, coordinate and finalize plans

## Primary Target Audience
* families planning travel
* reunions and larger trips need connected planning

## Secondary Target Audience
* college students planning trips
* coordination with varied schedules may be difficult

# Least Viable Product
* calendar with schedule
* ability to add events
* budgeting page
* list of necessary items
  
# General User Workflow
1. login to application
2. view page of schedule, budget, and plans
3. interact with various pages as needed
4. close application
   
# Future Alterations
* system to vote for events
* groupchat to discuss plans
