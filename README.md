# TeamProject
## Kevin Ying, Elisa Tandra, Yicheng Deng, Isaac Cheung, Tristan Medford
## Purpose
This project aims to answer the the FBLA Mobile Application Development prompt for 2026-2027. It aims to develop an application to streamline the process of planning a trip by allowing different people to collaborate and schedule, budget, and organize their trip.
## Audience
The audience for this project is anyone who is planning a vacation.
## Outside Destination
This application should be able to run on iOS, however a browser alternative may be used for early stages.
## Prototype
In the prototype users should be able to add events and budget.
## Next Steps
In the coming weeks we will work on finishing the prototype. This will likely be web based and we will move it to a mobile application later.
